About This Project

Diabetes Risk Prediction is a machine learning-based project designed to estimate diabetes risk using patient health information.

Technologies Used

  • Python
  • Flask
  • Pandas and NumPy
  • Scikit-learn
  • HTML, CSS and Bootstrap
  • Machine Learning

Algorithms Used

  • Logistic Regression
  • K-Nearest Neighbors (KNN)
  • Decision Tree
  • Random Forest
  • Support Vector Machine (SVM)

This project is developed for educational purposes. Its predictions are not medical diagnoses.
